## 2. 初期プラン（壁打ち前のたたき台）

Phase 0（0〜1ヶ月・0→50人）: 修吾の個人ネットワーク・知人のマイクロ法人オーナーへの直接声かけ、フェイクドアLPのメール登録者への個別招待。

Phase 1（1〜3ヶ月・50→300人）: X直接アプローチ、コンテンツSEO（note/Zenn）、招待制ウェイトリストによるFOMO演出、マイクロ法人系コミュニティへの参加。

Phase 2（3〜6ヶ月・300→1000人）: 確定申告シーズン（1〜3月）に照準を合わせたPR、法人設立代行/バーチャルオフィス業者との提携、インフルエンサー起用。

## 3. 壁打ち第1ラウンドでの指摘と決定事項

| 指摘者 | 指摘内容 | 決定事項 |
|---|---|---|
| ノア | 「1000ユーザー」の定義が曖昧（ウェイトリスト登録とアクティブ利用は別物） | **KPIを「β利用開始（CSV取込1回以上）1000人」に再定義**。ウェイトリスト数とは別集計とする |
| ノア | X直接アプローチ「1日10〜20件」の実行主体が不明確。自動化はスパムリスクあり | **自動化せず、修吾本人が1日15分・質重視5件に縮小**して実行する |
| ノア | 「確定申告シーズン(1〜3月)に合わせる」という前提はフリーランス限定の話。マイクロ法人は決算期を自由に選べるため需要は年間で分散（`sample-financialreport`の会社も5月〜翌4月決算だった） | **セグメント別に訴求タイミングを分離**：フリーランスは1〜3月に集中投下、マイクロ法人は「今すぐ始めても問題ない」という通年訴求にする |
| ジャービス | 「AI CEOジャービス」というPR切り口が、税務・会計という信頼性重視の領域で「ネタ扱い」されるリスク | **PRのフックとしては使うが、必ず「本人申告支援ツール型・税理士法対応」の一文を併記**し、信頼性を担保する |
| ジャービス | 母数50〜300人の段階で招待制ウェイトリストのFOMO演出は機能するか | **その規模では機能しないと判断**。当面は実名ユーザーの一言レビュー掲載を優先し、バイラル設計（紹介プログラム等）は300人到達後に本格投入する |

## 4. 壁打ち第2ラウンドでの指摘と決定事項

| 指摘者 | 指摘内容 | 決定事項 |
|---|---|---|
| ジャービス | 複数チャネル（SEO・X・コミュニティ・提携）を同時並行するのは、ソロファウンダー体制では実行不可能では | **最初の1ヶ月はX直接アプローチに一本化**。他チャネルは種まき程度に留め、本格投入は検証後に判断する |
| ノア | チャネルを1つに絞るならXを推す理由：①SEOは効果が出るまで数ヶ月かかる ②コミュニティ・提携は今のプロダクト完成度ではまだ早い ③Xだけが「即日・一人で・即座に反応が見える」の3条件を満たす | 上記の通りX一本化を採用 |
| ジャービス（レンへの確認） | 競合（freee/MF等）を名指しした比較コンテンツの法的リスクは | レン: 客観的な事実に基づく比較自体は景表法・不正競争防止法上おおむね許容されるが、誹謗表現や古い価格情報での比較は信用毀損リスクになる。**比較コンテンツは①価格確認日を明記 ②一次情報にリンク ③「本人申告支援ツール」の一文を毎回併記の3ルールで作成する** |
| ジャービス | 貸借対照表・別表一など様式精度の高い開発投資は、獲得（0→50人）段階で本当に必要か | ノア: 最初の50人は「明細を入れると仕訳と概算税額が出る」だけで十分刺さる。様式精度は「継続利用するか」の定着要因であり、「最初に試すか」の意思決定にはほぼ影響しない。**直近1〜2週間は新機能開発を止め、X直接アプローチの実行にリソースを寄せる**。決算書類の精度向上は50人到達後（定着フェーズ）の投資と位置づけ直す |

## 5. 最終アクションアイテム

- [ ] KPIを「β利用開始（CSV取込1回以上）1000人」として計測基盤を整える（ウェイトリスト登録数とは別集計）
- [ ] 修吾: 1日15分、Xで悩み言葉（「税理士 顧問料 高い」「一人社長 経理」等）への質重視の共感リプライ／DM招待を5件/日、直近1ヶ月継続
- [ ] ノア: フリーランス向け訴求は1〜3月の確定申告シーズンに向けたコンテンツ・PRを準備。マイクロ法人向け訴求は通年の「今すぐ始めるべき」メッセージに再設計
- [ ] ノア: 比較コンテンツ作成時は「価格確認日の明記」「一次情報へのリンク」「本人申告支援ツールである旨の併記」の3ルールを徹底
- [ ] レン: 比較コンテンツのひな形（免責文言テンプレート）を用意
- [ ] 開発サイドは直近1〜2週間、新機能追加を停止し、成長施策の実行を優先。決算書類まわりの精度向上は50人到達後に再開を検討
- [ ] 300人到達時点で、紹介プログラム／バイラル設計の本格検討に着手
