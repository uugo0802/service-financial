# デザイン刷新 — 基盤（トークン・コンポーネント・ダッシュボード適用）

## 背景・目的

現状のUI（stone系グレー＋amber）は、機能ごとに並列開発するエージェント体制の中で、UI/UXを横断チェックする工程が無いまま積み上がってきた。色自体は既存実装のコピーによって偶然揃っているだけで、影・角丸・余白のリズム・アイコン・状態変化といった「見た目に魂を入れる」部分は誰も手を入れていない。加えて `globals.css` の `body` に `font-family: Arial` が直書きされており、読み込んでいる Geist フォントが実際には適用されていない実装バグもある。

対策として、個別ページを1枚ずつ直すのではなく、**デザインシステム（トークン＋コンポーネント）を1つ作り、まずダッシュボード画面に適用して検証する**。全ページへの展開はこの基盤ができてから別スペックで進める（本スペックのスコープ外）。

## ブランドパーソナリティ

- **方向性**: モダンSaaS系（濃紺/黒基調のダークUI中心）。ライト/ダーク/システムの3段階切り替えは既存の `ThemeToggle.tsx` / `data-theme` 属性の仕組みをそのまま使う（新規実装不要）
- **配色バリエーション**: ニュートラルブラック（青みのない純粋な黒〜グレー）を採用。ネイビースレート案は不採用
- **アクセントカラー**: 緑系（会計・お金を連想させつつ派手すぎない）
- **明示的に避けるもの**: 絵文字アイコン（「AIが作ったっぽい」という指摘を受けたため）。紫〜青グラデーション・丸角＋ふわっと影のカード・抽象的なコピーは今回は特に問題視されていないため制約しない
- **書類プレビュー（申告書等の役所提出書類を模した画面）は対象外**: テーマ切り替えに関わらず常に白い紙のまま固定する

## スコープ

**含む**:
- デザイントークン（色・タイポグラフィ・角丸）の定義
- `lucide-react` の導入とアイコン方針
- 基本UIコンポーネント（`Card` / `Button` / `Badge` / `Input`）の新規作成
- Geist フォントが実際に適用されるよう `globals.css` のバグを修正、serif見出しの廃止
- ダッシュボード画面（`app/src/app/dashboard/page.tsx` とその子コンポーネント群）への適用

**含まない（別スペックで対応）**:
- ダッシュボード以外の画面（取引検索、書類一覧、申告書プレビュー等）への展開
- 書類プレビュー画面のスタイル変更（常に白固定のため対象外）
- `.viz-dashboard` のグラフ配色変更（色覚多様性検証済みのため現状維持）
- shadcn/ui・Radix等の外部UIキットの導入（今回はフルカスタムで進める）

## デザイントークン

### カラー

| 用途 | ライト | ダーク |
|---|---|---|
| 背景 | `#ffffff` | `#0a0a0a` |
| サーフェス（カード等） | `#fafafa` | `#141414` |
| ボーダー | `#e5e5e5` | `rgba(255,255,255,0.08)` |
| 本文テキスト | `#171717` | `#e5e5e5` |
| 副次テキスト | `#737373` | `#a3a3a3` |
| アクセント（緑） | `#16a34a` | `#22c55e` |
| 危険（エラー・支出） | `#dc2626` | `#f87171` |

`app/src/app/globals.css` の `:root` / `:root[data-theme="dark"]` / `:root[data-theme="light"]` 各ブロックの値をこの表の内容に置き換える。`:root[data-theme="dark"]` は現状 `--background`/`--foreground` の2変数のみだが、上記の `--surface` / `--border` / `--muted` / `--accent` / `--danger` を新規のCSS変数として追加する。

### タイポグラフィ

- `body` の `font-family: Arial, Helvetica, sans-serif` の直書きを削除し、`@theme inline` で定義済みの `--font-sans`（Geist）が実際に効くようにする
- 見出しの `font-serif` 指定（`DashboardPage` の `税務申告AI／ジャービス` 見出し等）は `font-sans` に変更する

### 角丸・影

- 角丸: 8〜10px（`rounded-lg` 相当）
- 影は使わない。要素の区切りは常に1pxボーダーで表現する

## コンポーネント

- `lucide-react` を新規依存として追加する
- `app/src/components/ui/` 配下に以下を新規作成する
  - `Card`: サーフェス色＋ボーダー＋角丸のラッパー。ダッシュボードの各セクション（`border border-stone-300 dark:border-stone-700 bg-white dark:bg-stone-900 rounded-md p-5` を都度書いている箇所）を置き換える
  - `Button`: プライマリ（緑背景）／セカンダリ（ボーダーのみ、背景透明）の2バリアント
  - `Badge`: 増減率・ステータス表示用の小さいラベル。`StatTile` の前年比パーセンテージ表示に使う
  - `Input`: フォーム入力の共通スタイル（今回のダッシュボード画面自体には入力フォームは無いが、`WidgetLayoutControls` 等の将来的な拡張のために合わせて作る）
- 既存の `StatTile` / `TrendLineChart` / `TrendBarChart` / `KpiTrendPanel` / `ExpenseBreakdownChart` / `BenchmarkPanel` はロジック・SVG描画部分はそのまま、外枠の見た目（色・枠線）のみ新トークン／`Card` に差し替える。グラフの配色（`.viz-dashboard`）はスコープ外なので変更しない

## 検証

- 明示的な単体テストは追加しない（見た目の変更が中心のため）。既存の Vitest 全件（2629件、`npm test`）がグリーンのまま保たれることを確認する
- `npm run lint` / `tsc --noEmit` がクリーンであることを確認する（ただし並行開発由来の既知の型エラー3件は本スペックの対象外なので許容する）
- 開発サーバー上でダッシュボード画面を実際に開き、ライト／ダーク両方の表示を目視確認する
