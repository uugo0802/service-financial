**UI/UX弱み・レビューでの不満（頻出）**

- セルフプランはサポートが実質ゼロで、詰まった時に自力解決するしかない
- プラン名・機能差が分かりにくい（機能同一でサポートだけ違う設計への戸惑い）
- 「1事業者1回ルール」（無料体験・初年度無償の重複利用不可）に関する注意喚起系の不満

### 1-4. 3社共通の不満構造（今回の調査での最重要ポイント）

1. **「自動化」を謳っても、結局は人間による仕訳確認・修正作業が残る**（freeeが最も顕著）
2. **申告書は下書きまでで、e-Tax/eLtax送信操作自体は依然としてユーザーが自力で行う必要があり、送信時エラー（利用者識別番号誤り、証明書失効、ブラウザ表示倍率問題など）に個人で対処しなければならない**
3. **法人（マイクロ法人）は会計と申告（法人税/消費税）が別商品・別課金になりがちで、合計コストの見通しが悪い**
4. **価格帯が「機能フル対応」の実質下限（消費税申告・電話サポートなど）に達すると税理士顧問料に近づいていく**ため、「安いはずなのに結局高い」という体感が生まれやすい
5. **スマホ対応の弱さ**（MF）、**サポート品質のばらつき**（freee/やよい）

## 2. AI一気通貫で刺さる差別化ポイント（5個）

1. **「仕訳確認ゼロ」を具体的KPIとして掲げる**
   競合はAI提案はするが最終確認は人間任せ。当社は「自動仕訳の自動確定率◯%以上、例外のみ人間レビュー」を数値公約にし、「もう仕訳画面を毎日開かなくていい」を訴求。freeeの「自動化を謳っているのに結局チェックが減らない」不満のど真ん中を突く。

2. **申告シーズンの"下書き→送信誘導"を一本のガイド動線に統合**
   競合は「申告書生成」までで終わり、e-Tax送信は国税庁側の画面・エラーに個人で対処させる。当社はチェックリスト形式で送信完了まで伴走し、送信エラー（証明書失効・表示倍率など）のFAQをリアルタイムで併走表示。「送信で詰まって離脱する」を防ぐ。

3. **マイクロ法人向けに「会計＋消費税＋法人税」の合計コストを1つの月額に統合**
   freee/MFは「ひとり法人プラン」＋別売り申告ソフトで実質価格が見えにくい。当社は最初から「月額◯円で法人税・消費税の概算試算まで込み」を明示し、「結局いくらかかるか分からない」不安を解消。

4. **低価格帯でも消費税申告・インボイス対応を最初から含める**
   MF・freeeとも下位プランは消費税非対応で、必要になった瞬間にアップセルされる設計。当社は「後から機能制限で足元を見られる」不満を逆手に取り、「価格帯を維持したまま必要機能を最初から含む」を差別化メッセージにする。

5. **サポートをAIチャットで即時・無制限にし、「電話サポートは上位プランのみ」という価格による情報格差を撤廃**
   やよい・freeeは電話サポートが上位プランの特典。AIが一次対応をカバーすることで、低価格プランでも「詰まったら即座に聞ける」体験を全プランで提供できる、という運用コスト構造ならではの強み。

## 4. 今日中に実施可能な最速PMF検証プラン（優先順位付き）

**優先度1: フェイクドアLP + 登録数計測**
上記コピー5本を使ったシングルページLP（セグメント別に2種：マイクロ法人向け／フリーランス向け）を今日中に公開し、「早期アクセス登録（メールのみ）」ボタンを設置。Google/X広告なしでもX投稿・note・知人経由で流入させ、24時間でのCVR（訪問→登録）とセグメント別の反応差を計測。閾値目安: 訪問100件でCVR5%以上なら継続検証に値するシグナルとみなす。

**優先度2: X（Twitter）での悩み投稿への直接リプライ／引用調査**
「確定申告 めんどくさい」「税理士 顧問料 高い」等のキーワードで直近投稿している個人事業主・一人社長アカウントを検索し、共感コメント＋LPリンクを添えて反応（いいね・クリック・DM）を計測。定性的な生の悩み言葉を収集し、コピーの磨き込みにも活用。当日中に30〜50件試せる規模感。

**優先度3: Xでの簡易アンケート投稿**
「確定申告/決算、どこが一番面倒？」（選択肢: 仕訳入力／申告書作成／e-Tax送信操作／税理士費用）という4択アンケートをマイクロ法人向け・フリーランス向けアカウントそれぞれに投稿し、母数と回答分布を翌日以降の優先機能決定に反映。即日の反応は薄くても、次のLP改善・機能訴求の一次データとして低コストで回せる。

実行順の理由: LP登録数（優先度1）が最も直接的な支払意思の代理指標になるため最優先。X直接アプローチ（優先度2）は生の言葉が拾える即効性の高い定性データ。アンケート（優先度3）は回答が集まるまでに時間がかかるため補助的に並走。
